# Shinano — Dreaming Moon

A cool moonlit palette in ink navy, silver, periwinkle, and soft gold, paired with your Shinano scrapbook artwork.

## Import the theme

In Kettu’s theme importer, paste this raw JSON link:

https://raw.githubusercontent.com/E32GX/shinano-dreaming-moon-assets/main/shinano-dreaming-moon-v2.json

The theme background uses your 720 × 1280 image from this same repository.

## Optional font

The theme format controls colors and background; it does not set fonts. The Nunito Sans companion CSS is here:

https://raw.githubusercontent.com/E32GX/shinano-dreaming-moon-assets/main/shinano-font.css

Use it only with a Kettu-compatible custom CSS or font plugin.
